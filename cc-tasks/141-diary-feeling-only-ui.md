# 141 日记前端只展示今日感受

## 目标

保留“今日事件”作为内部记忆数据，但日记列表和详情页只展示“今日感受”。

## 现状

- `core/scheduler/triggers/time_based.py` 生成 `## 今日事件` 与 `## 今日感受` 两段。
- `admin/routers/diary.py` 当前详情接口返回整篇 `body`。
- prompt 内部仍需要事件层参与记忆召回；不能删除或改成只存感受。

## 实施范围

1. 在日记读取侧用结构化解析拆出 `facts` 与 `feeling`，兼容无标题的旧格式。
2. `/diary/list` 的标题改由感受层生成；没有感受时使用明确空状态。
3. `/diary/{date}` 对前端返回感受层；事件层只供内部读取/搜索接口使用。
4. 前端更新详情展示和空状态，不显示事件层。
5. 更新对应 API/UI 测试；不改变 prompt 的事件召回契约。

## 验收

- 前端看不到“今日事件”正文。
- 角色搜索日记或事件记忆时仍能命中客观事件。
- 新旧格式日记都能正常读取。
- 修改直接加载的静态资源时同步更新版本参数。
