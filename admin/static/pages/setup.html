基础聊天模型 必填①

日常对话实际调用的模型连接。已配置 model_presets 时写入当前生效路由的主聊天 preset；未配置时写入旧版 llm: 块——两种情况都会自动识别，不需要你判断。更细粒度的多模型 preset / 路由切换见「模型路由」页。

💡 当前用的还是内置占位角色卡（"角色名"），去「角色卡」页创建/编辑属于你自己的角色，聊天才会有真实人设。

Owner ID 必填②

建议直接填你的 QQ 号——若此处用了别的 id，之后接 QQ 时会按 QQ 号另起一套记忆，与桌宠期记忆不互通。留空 = 主动触发调度器会静默跳过主动消息，且记忆文件可能挂在错误/缺省 uid 下。

语义 Embedding 强烈建议

作用：长期记忆语义召回（情景记忆/往事检索按语义匹配而非纯关键词）。缺失后果：召回质量降级为关键词匹配，不会导致聊天崩溃或阻塞（fail-open）。

邮件通道 可选

角色写信功能的 SMTP 发信配置；默认关闭，纯增值功能。总开关也可以在「Token」页「通道开关」区切换。

自定义纪念日 可选

letter_writer / festival 消费；命中当天会主动提起。JSON 数组编辑，字段：key/month/day 必填，year_start 留空=每年都当作第 0 年（只用 prompt_zero），prompt_zero/prompt_years 可选（prompt_years 支持 {char}/{years} 占位符）。

Obsidian 日记路径 可选

日记读取功能（daily_journal/diary_reminder/diary_inject）读取此目录下按 YYYY-MM-DD.md 命名的日记文件；不填则回落到本地 fallback 目录。角色白名单（diary.characters）不在本页编辑。

Coplay 后台游戏检测白名单 可选

陪玩模式（coplay）用于识别非 Steam 游戏：armed 状态下按 process_name 做 psutil 进程名匹配（大小写不敏感，.exe 可写可不写）。save_dir 可选，填了才会做存档变化检测。JSON 数组编辑，name/process_name 必填。
